## 3. 사용자가 직접 쓴 원문 — 작년 아내 생일 축하 메시지 (몽골어)

> 이 글은 **화자의 실제 목소리**다. 문체·어휘·감정 밀도의 기준선으로 삼는다.

```
🌹 Төрсөн өдрийн мэнд хүргэе, хайрт минь!
Амьдралын минь гэрэл, хоёр үрийн минь халамжит ээж, гэр бүлийн минь түшиг тулгуур болсон чамдаа төрсөн өдрийн баярын халуун мэндийг хүргэе.
Чиний инээмсэглэл бидний гэрийн хамгийн дулаан нарны туяа, хоёр хүүхдийн минь хамгийн том хамгаалагч бурхан.
Гэрийн бүх арын ажлыг ухаалаг дуугүйхэн дааж, бид гурвыг аз жаргалтай байлгаж өгдөг чамдаа би өдөр бүр талархдаг.
Чи миний нүдэнд хамгийн хүчтэй, хамгийн үзэсгэлэнтэй эмэгтэй, амьдралын минь аз жаргалын жинхэнэ эзэн.
Чамдаа үүрд хайртай, чи минь инээмсэглээд аз жаргалтай байх нь миний хамгийн том хүсэл шүү! ❤️✨🎂
```

여기서 이미 확립된 화자의 핵심 이미지 — 재사용하되 반복이 아닌 **심화**로 발전시킨다:
- `Амьдралын минь гэрэл` (내 삶의 빛)
- `түшиг тулгуур` (기둥·버팀목)
- `хамгийн дулаан нарны туяа` (가장 따스한 햇살)
- `хамгаалагч бурхан` (수호신)
- `ухаалаг дуугүйхэн дааж` (지혜롭게 말없이 감당하며) ← 이번 서사의 미안함 정서와 직결

## 4. 아내가 남편에게 써준 시 — 2021년 남편 생일 (몽골어)

> **이 시가 이 프로젝트의 정서적 심장이다.** 두운(толгой холбох) 구조를 정확히 관찰하라.

```
Бүрэнхий байсан хорвоо гэрэлтэж
Бүүдгэр байсан наран мишээж
Гундаж удсан цэцгүүд өндийж
Гэрэл гэгээтэй хамт чи минь ирсэн билээ
                     хайртай шүү ❤️❤️❤️
Khairdaa ene horwood mendelsen bayrt udriin mendiig hurgeyee 🥰   kisss yaa 😘
```

구조 분석:
- 1행 `Бү-` / 2행 `Бү-` / 3행 `Гу-` / 4행 `Гэ-` → **2행씩 짝지은 두운(AABB)**. 몽골 전통 운문의 정형이다.
- 의미: 어스름하던 세상이 밝아지고 / 흐리던 해가 미소 짓고 / 시들어 있던 꽃들이 고개를 들고 / 빛과 함께 네가 왔더라
- **핵심 서사 장치:** 아내는 남편을 "빛을 데려온 사람"으로 노래했다. 그런데 남편은 아내를 "내 삶의 빛"이라 부른다. → **서로가 서로의 빛이었다**는 회답 구조를 이번 사이트의 결말로 삼는다. 이것이 이 프로젝트 고유의 서사 축이다.
- 마지막 줄은 로마자 표기(비공식 몽골어 채팅 표기)다. 두 사람의 실제 대화 질감이므로 어딘가에 그대로 살릴 가치가 있다.

## 5. 화자가 전하고 싶은 감정 (사용자 원문)

> "사실 집사람이 너무 총명하고 지혜롭고 두아이를 키우면서 든든하게 나를 지원해주고 있는대 그에 반해 너무 못난거같에서 내가 항상 미안하고 투박하고 내사람이라서 더 막대하는게 거같에 내가 이세상 제일 중요한사람한테 너무 미안해 항상 그런 마음을 좀 녹인 스토리가 있어야될거같고"

> "앞으로도 힘내서 서로 보필하고 행복하게 잘살자는게 내 목표고"

감정 좌표 3축 — 서사는 반드시 이 셋을 모두 통과해야 한다:
1. **감탄** — 아내의 총명함·지혜·강인함에 대한 경외
2. **자책과 사과** — "가장 가까운 사람이라서 더 함부로 했다"는 구체적 미안함. 이 사이트의 존재 이유.
3. **약속** — 앞으로 서로 보필하며 살자는 다짐

주의: 2번을 무겁게 쓰면 생일이 무거워진다. **사과는 짧고 정확하게, 감사와 약속은 길고 따뜻하게.**
