1. 아래 **파일명 그대로** 저장 (이름이 다르면 안 나타납니다)

파일명은 반드시 소문자 `.jpg`입니다. `.JPG`(대문자)는 GitHub Pages에서 404가 납니다.
아이폰 사진(`.HEIC`)은 브라우저가 못 엽니다 → JPG로 변환해서 넣어주세요.

## 고르실 때 팁

- **비율은 안 맞아도 됩니다.** 자동으로 잘립니다. 다만 얼굴이 사진 가장자리에 있으면 잘릴 수 있으니, 가운데 위쪽에 있는 사진이 안전합니다
- 화질보다 **표정**이 중요합니다. 흐릿해도 웃고 있는 사진이 낫습니다
- 아내분이 예쁘게 나온 걸 고르세요. 이 페이지의 주인공은 아내분입니다

## 용량 줄이기 (중요)

원본 사진은 보통 한 장에 3~5MB입니다. 15장이면 50MB가 되어 **휴대폰에서 안 열립니다.**
넣기 전에 크기를 줄여주세요.

**가장 쉬운 방법:** 카카오톡으로 자기 자신에게 사진을 보낸 뒤 다시 저장하면 자동으로 압축됩니다.

**ImageMagick이 있으시면:**

```bash
mogrify -path assets/img/ -resize "1600x1600>" -quality 82 -strip *.jpg
```

**아이폰 HEIC 변환:**

```bash
magick input.HEIC -resize "1600x1600>" -quality 82 output.jpg
```

목표: **한 장당 400KB 이하, 전체 5MB 이하.**
