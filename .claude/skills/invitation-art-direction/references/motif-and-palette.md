# 팔레트·모티프·모션 참조

## 1. 팔레트 원칙

청첩장 감성의 팔레트는 **저채도 3색 + 강조 1색**을 넘지 않는다. 색이 많아지면 즉시 촌스러워진다.

구성: 바탕(paper) / 잉크(ink) / 보조(muted) / 강조(accent). 강조색은 전체 화면의 5% 미만에만 쓴다.

### 후보 A — Warm Paper (기본 권장)
한지·미색 종이의 따뜻함. 가족 서사에 가장 안전하고 잘 어울린다.
```css
--paper:  #F7F3EC;   /* 바탕 */
--paper2: #EFE8DC;   /* 섹션 구분 */
--ink:    #2E2A26;   /* 본문 */
--muted:  #8B8177;   /* 보조 텍스트, 한국어 */
--accent: #A8563F;   /* 테라코타 — 날짜, 강조 */
--dark:   #1B1815;   /* 절정 씬 배경 */
```

### 후보 B — Deep Night
밤·별·초원의 하늘. 절정 씬과 프롤로그에 강하지만, 전체를 어둡게 하면 무거워진다.
```css
--paper:  #12161C;
--ink:    #EDE7DC;
--muted:  #8A93A0;
--accent: #C9A227;   /* 낡은 금색 */
```

### 후보 C — Steppe Dawn
초원의 새벽. 몽골적이면서 서정적.
```css
--paper:  #FBF6EE;
--ink:    #33302B;
--muted:  #9A8F80;
--accent: #6E8B74;   /* 흐린 초원 녹 */
```

**권장 운용:** A를 기본으로 쓰고, 절정 씬 한 곳에서만 `--dark` 배경으로 반전시킨다. 전체 흐름이 밝다가 절정에서 한 번 어두워지는 낙차가 감정을 만든다.

## 2. 타이포 스케일

```css
--fs-display: clamp(28px, 8vw, 44px);   /* 표지, 절정 */
--fs-h1:      clamp(22px, 6vw, 30px);   /* 씬 헤드라인 */
--fs-body:    clamp(15px, 4.2vw, 17px); /* 몽골어 본문 */
--fs-ko:      clamp(12px, 3.4vw, 14px); /* 한국어 (본문의 약 0.82배) */
--fs-caption: 12px;
--lh-body:    1.9;   /* 키릴 본문은 넉넉한 행간이 필요하다 */
--lh-verse:   2.2;   /* 운문은 더 넉넉하게 */
--ls-display: 0.02em;
```

키릴 문자는 라틴보다 획이 촘촘해 보여, 행간이 좁으면 답답해진다. `line-height: 1.9` 이상을 권장한다.

운문은 **행 단위로 줄바꿈이 강제**되어야 한다. 두운은 각 행의 첫 글자가 세로로 정렬되어 보일 때 시각적으로도 완성된다. 자동 줄바꿈으로 행이 접히면 두운 구조가 눈에서 사라진다 — 절정 씬 폰트 크기는 **가장 긴 행이 한 줄에 들어가는 크기**로 정한다.

## 3. 여백 체계

```css
--sp-1: 8px;   --sp-2: 16px;  --sp-3: 24px;
--sp-4: 40px;  --sp-5: 64px;  --sp-6: 96px;  --sp-7: 140px;
```

씬 사이 세로 여백은 `--sp-6` 이상. 스크롤 스토리텔링에서 여백은 **시간**이다. 여백이 짧으면 이야기가 급해 보이고, 넉넉하면 읽는 사람이 감정을 처리할 틈이 생긴다. 절정 직전 씬의 여백은 의도적으로 더 넓힌다 — 침묵이 다음 장면을 크게 만든다.

## 4. 몽골 전통 모티프

**은유적으로만 쓴다.** 민속 테마 페이지가 되면 청첩장 감성이 사라진다. 모티프는 장식이 아니라 **서명**이다 — 있는 줄 모르게 있어야 한다.

| 모티프 | 의미 | 사용법 |
|--------|------|--------|
| **Улзий хээ** (무한 매듭) | 끊이지 않는 인연, 영속 | 섹션 구분자에 아주 작게(16px), `--muted` 색, 투명도 0.3 |
| **Хас хээ** (만자 문양) | 영원 | 코너 장식. 매우 절제해서 |
| **Эвэр угалз** (뿔 문양) | 곡선 당초무늬 | 얇은 구분선의 양 끝 마감 |
| **Тооно** (게르 천창) | 하늘, 가정의 중심 | 원형 이미지 마스크 |

권장: **구분자 하나만 골라 전 씬에서 반복**한다. 여러 문양을 섞으면 산만해진다. SVG로 인라인 삽입하면 색을 `currentColor`로 상속받아 다크 배경에서도 동작한다.

## 5. 모션 어휘

허용 속성은 `transform`과 `opacity`뿐이다. 그 외 속성 애니메이션은 모바일에서 즉시 끊긴다.

| 이름 | 값 | 용도 |
|------|----|------|
| `fade` | opacity 0→1, 700ms ease-out | 기본 |
| `fade-up` | + translateY(16px→0), 800ms | 텍스트 블록 |
| `fade-up-lg` | + translateY(32px→0), 1000ms | 고조 씬 |
| `image-settle` | scale(1.06→1), opacity 0→1, 1200ms | 사진 진입 |
| `verse-cascade` | 행별 fade-up, 220ms 간격 | **절정 전용** |

`verse-cascade`가 절정의 특별 연출이다. 4행이 한 줄씩 차례로 떠오르면, 읽는 속도가 강제로 느려지면서 각 행의 두운이 인지된다. 다른 씬에서는 절대 쓰지 않는다.

이징은 `cubic-bezier(0.22, 1, 0.36, 1)` 계열로 통일한다. 되튐(overshoot)이 있는 이징은 이 정서에 맞지 않는다.

**`prefers-reduced-motion`을 존중한다.** 해당 설정에서는 모든 모션을 즉시 표시로 대체한다. 멀미를 느끼는 사람에게 시네마틱 스크롤은 고문이다.

## 6. 사진 처리

```css
--img-radius: 2px;        /* 큰 라운드는 청첩장 정서를 해친다 */
--img-ratio-hero: 4/5;    /* 세로 — 모바일에서 강하다 */
--img-ratio-std: 3/2;
--img-ratio-gallery: 1/1;
```

색 보정은 통일한다. 여러 해에 걸쳐 다른 기기로 찍은 사진들은 색온도가 제각각이다. 옅은 웜톤 필터를 전 사진에 공통 적용하면 하나의 앨범처럼 묶인다.

```css
.photo { filter: saturate(0.92) contrast(1.02) sepia(0.06); }
```

과하면 인위적이 된다. 위 수치가 상한선이다.
