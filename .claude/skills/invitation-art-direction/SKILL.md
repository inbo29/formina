# Invitation Art Direction — 절제된 시네마틱 스크롤

## 이 스타일의 본질은 절제다

모바일 청첩장이 아름다운 이유는 화려해서가 아니라 **비어 있어서**다. 여백, 얇은 선, 조용한 세리프, 낮은 채도. 감정은 요소가 아니라 요소 사이의 공간에서 발생한다.

애니메이션은 "나타남" 하나면 충분하다. 튀거나(bounce) 회전하거나 번쩍이는 순간 이 정서는 즉시 파괴된다. 이 페이지는 광고가 아니라 편지다.

## 제1 제약: 다국어 타이포그래피

**폰트 선택이 다른 모든 디자인 결정에 우선한다.** 몽골어 키릴에는 `Өө Үү`가 있고, 많은 장식용 폰트가 이 글리프를 갖고 있지 않아 두부(□)로 렌더링된다. 한글 지원까지 필요하면 후보는 더 좁아진다.

**글리프가 없는 아름다운 폰트보다 글리프가 있는 평범한 폰트가 무조건 낫다.** 이건 취향 문제가 아니다.

안전한 조합:
```css
--font-mn: 'Noto Serif', Georgia, serif;        /* 키릴 확장 포함 */
--font-ko: 'Noto Serif KR', 'Nanum Myeongjo', serif;
--font-num: 'Cormorant Garamond', Georgia, serif; /* 숫자·연도 전용 장식 */
```
날짜와 연도만 별도 장식 폰트를 쓰는 것이 안전하다. 숫자는 글리프 커버리지 문제가 없고, 여기서만 우아함을 벌어도 전체 인상이 달라진다.

**몽골어는 한국어보다 길다.** 같은 뜻의 문장이 눈에 띄게 길어진다. 고정 높이 컨테이너는 반드시 넘친다 — 모든 텍스트 블록은 세로로 자라도 깨지지 않게 설계한다.

**이중언어 위계를 정하고 끝까지 지킨다.** 몽골어가 주(크고 진하게), 한국어가 종(작고 옅게, 약 0.8배 크기, 낮은 대비). 병기든 토글이든 이 위계는 변하지 않는다.

## 모바일이 원본이다

받는 사람은 침대에서 휴대폰으로 이 페이지를 연다. 375px에서 완벽해야 하고, 넓은 화면은 콘텐츠 폭을 제한해 우아하게 확장한다. 데스크톱 레이아웃을 먼저 그리고 축소하면 반드시 실패한다.

```css
--content-max: 640px;   /* 이 이상 넓어지지 않는다 */
--gutter: 24px;
```

## 감정 곡선의 시각화

작가가 준 `intensity 1~5`를 시각 강도로 번역한다.

| intensity | 여백 | 타이포 | 이미지 | 연출 |
|-----------|------|--------|--------|------|
| 1 담백 | 표준 | 본문 크기 | 작게, 자연색 | 단순 페이드 |
| 2 서정 | 표준 | 헤드라인 | 중간 | 페이드 + 8px 상승 |
| 3 고조 | 넓게 | 큰 헤드라인 | 크게 | 페이드 + 16px 상승, 이미지 살짝 스케일 |
| 4 긴장 | 매우 넓게 | 큰 헤드라인 | 전면 | 어둡게 깔고 텍스트 대비 강화 |
| 5 절정 | 화면 전체 | 시 조판 | 없거나 최소 | **이 씬 전용 연출 하나** |

**intensity 5의 특별 연출은 단 한 번만 쓴다.** 재사용하는 순간 특별함이 사라진다.

절정이 시(운문)라면 이미지를 빼는 편이 강하다. 사진과 시가 같은 화면에서 경쟁하면 둘 다 약해진다. 검은 화면에 흰 글씨 4행만 남기는 것이 이 프로젝트에서 가장 강력한 선택지다.

## 레이아웃 아키타입

씬마다 새로 디자인하지 않는다. 5~6개 아키타입을 정하고 조합한다. 반복되는 리듬이 곧 편집 디자인의 완성도다.

| 아키타입 | 구성 | 용도 |
|---------|------|------|
| `cover` | 전면 이미지 + 중앙 세로 정렬 텍스트 | 프롤로그, 표지 |
| `photo-full` | 전면 이미지 + 하단 캡션 | 사진이 주인공인 씬 |
| `photo-split` | 이미지 + 텍스트 블록 (모바일에서는 세로 적층) | 일반 연표 씬 |
| `text-only` | 텍스트 + 넓은 여백 | 감정 씬, 전환점 |
| `center-verse` | 어두운 배경 + 중앙 정렬 운문 | **절정 전용** |
| `interlude-gallery` | 작은 이미지 2~4장 가로 배열 | 아이 성장 인터루드 |
| `letter` | 편지 조판 + 서명 | 에필로그 |

## 사진 없이 완성되게 설계한다

사진은 항상 마지막에 도착한다. 모든 이미지 슬롯은 사진이 없어도 성립하는 상태를 갖는다 — 종이 질감 배경 + 얇은 테두리 + 연도 숫자. 플레이스홀더가 흉하지 않으면 사진이 늦어도 페이지를 보여줄 수 있다.

사진의 가로세로비는 제각각이다. `aspect-ratio` + `object-fit: cover`로 고정 비율 크롭 규칙을 정한다. 인물 사진에서는 `object-position` 기본값을 상단 쪽(`center 35%`)에 두는 편이 얼굴이 잘릴 확률이 낮다.

## 출력

`artdirection.md` — 팔레트, 타이포 스케일, 여백, 모티프. **모두 CSS 커스텀 프로퍼티 값으로.** `"따뜻한 베이지"`가 아니라 `--paper: #F7F3EC;`로 쓴다. 엔지니어가 색을 상상하게 하지 않는다.

`scenes.json` — 씬별 `layout`, `visual_intensity`, `enter`, `media_treatment`, `special`, `notes_for_engineer`.

구체적 팔레트 후보와 몽골 전통 모티프 활용법은 `references/motif-and-palette.md` 참조.
