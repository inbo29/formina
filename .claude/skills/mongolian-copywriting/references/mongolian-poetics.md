## 1. 두운 (толгой холбох)

몽골 운문의 정의적 특징. "толгой"는 머리, "холбох"는 잇다 — **행의 머리를 잇는다.**

### 패턴

| 형식 | 구조 | 특징 |
|------|------|------|
| AAAA | 4행 모두 같은 음절로 시작 | 가장 전통적이고 격식 있음. 축원문에 흔함 |
| AABB | 2행씩 짝지음 | 현대 서정시에 흔함. 짓기 쉽고 자연스러움 |
| ABAB | 교차 | 드묾 |

맞추는 단위는 **첫 음절**이며, 첫 자음만 같아도 성립하는 느슨한 형태부터 첫 음절 전체가 같은 엄격한 형태까지 폭이 있다. `Бүрэнхий / Бүүдгэр`는 첫 음절 `Бү`가 완전히 일치하는 엄격한 쪽이다.

### 짓는 순서

1. 전하려는 의미를 산문으로 먼저 확정한다
2. 그 의미의 핵심어를 몽골어로 고른다
3. 핵심어 중 **첫 음절이 같은 것들을 찾는다** — 이것이 두운의 씨앗이 된다
4. 씨앗 음절에서 시작하는 다른 어휘를 모아 행을 만든다
5. 어색한 행이 하나라도 있으면 씨앗을 바꿔 처음부터 다시 짓는다

의미를 운에 맞추는 게 아니라, **의미에 맞는 운을 찾는다.** 순서가 뒤집히면 반드시 어색해진다.

### 회답시 (답가)

상대가 준 시의 두운 음절을 되받는 기법. 같은 음절로 시작하되 내용은 답이 되게 한다.

원시가 `Бү-Бү-Гу-Гэ`(어둠 → 빛이 왔다)라면, 답시는 같은 `Бү`와 `Гэ`를 쓰되 **주어를 뒤집는다** — "빛을 데려온 건 너였다"로. 받는 사람이 자기 시의 운을 알아채는 순간 효과가 발생한다.

## 2. 전통 장르: ерөөл과 магтаал

| 장르 | 성격 | 쓰임 |
|------|------|------|
| **ерөөл** (축원) | 미래를 향한 축복. "~하기를" | 생일, 결혼, 새해, 새집. **생일 축하문의 정통 형식** |
| **магтаал** (찬가) | 대상의 훌륭함을 기림 | 사람·자연·말(馬)을 칭송 |

생일·기념일 글은 **магтаал(당신은 이런 사람이다) → ерөөл(이러하기를 빈다)** 순서로 짜면 전통적 리듬을 얻는다. 찬양으로 시작해 축복으로 닫는 이 구조는 몽골 화자에게 익숙하다.

ерөөл의 전형적 마무리 어미: `-аарай/-ээрэй/-оорой/-өөрэй` (기원), `болтугай` (~하기를, 격식체).

## 3. 문화적 이미지 사전

몽골어 서정문에서 살아 있는 이미지들. 번역된 비유보다 이쪽이 훨씬 강하다.

| 몽골어 | 뜻 | 정서적 함의 |
|--------|----|-----------|
| `гал голомт` | 화덕·가정의 불 | **가정 그 자체.** 불을 지키는 사람이 곧 가정을 지키는 사람. 아내·어머니에게 쓰기에 가장 강력한 이미지 |
| `түшиг тулгуур` | 버팀목·기둥 | 게르의 기둥에서 온 말. 의지하는 존재 |
| `гэрэл` / `гэгээ` | 빛 / 광명 | 희망, 삶의 의미 |
| `нарны туяа` | 햇살 | 따스함 |
| `хөх тэнгэр` | 푸른 하늘 | 영원, 신성 |
| `цагаан сэтгэл` | 흰 마음 | **순수하고 선한 마음.** 흰색은 몽골에서 상서로움 |
| `буян` | 공덕·복 | 선행이 쌓여 만든 복 |
| `энэрэл` | 자애 | 어머니의 사랑 |
| `үр хүүхэд` | 자식들 | |
| `хань` | 반려 | 배우자를 이르는 정다운 말 |
| `амьдралын хань` | 인생의 반려 | 배우자에 대한 가장 따뜻한 표현 중 하나 |
| `мөнх` | 영원한 | |
| `тэвэр` | 품·포옹 | |
| `сүү` / `цагаан идээ` | 젖 / 유제품 | 어머니, 생명, 정결 |

`гал голомт`은 이 종류의 글에서 특히 값지다. 아내를 "우리 집 불을 지켜온 사람"으로 부르는 것은 몽골 문화에서 최고 수준의 헌사이며, 한국어로는 대응어가 없다.

## 4. 친밀도와 호칭

| 표현 | 친밀도 | 용법 |
|------|-------|------|
| `та` | 존칭 | 손윗사람, 공식. **배우자에게 쓰면 거리감** |
| `чи` | 친밀 | 부부·연인·친구. 이 종류의 글의 기본값 |
| `чи минь` | 매우 친밀 | "너, 내 사람" — 애정의 표지 |
| `хайрт минь` | 매우 친밀 | "내 사랑" |
| `хонгор минь` | 매우 친밀 | "내 귀염둥이" — 더 다정하고 장난스러움 |
| `амраг минь` | 연인적 | 낭만적 색채가 강함 |

불변화사 `минь`(나의)는 온도 조절 장치다. 붙이면 따뜻해지고 빼면 서술적이 된다. 다만 모든 문장에 붙이면 느끼해진다 — **감정이 올라가는 지점에 선택적으로** 쓴다.

## 5. 모음조화

몽골어 단어는 한 종류의 모음 계열로만 구성되며, 어미도 어간을 따른다.

| 계열 | 모음 |
|------|------|
| 남성(후설) | а, о, у |
| 여성(전설) | э, ө, ү |
| 중성 | и (양쪽과 결합) |

어미 변이 예: 탈격 `-аас / -ээс / -оос / -өөс`, 기원 어미 `-аарай / -ээрэй / -оорой / -өөрэй`.

`Эрдэнэ`(전설 계열) → `Эрдэнээс`. `Болд`(후설) → `Болдоос`.

모음조화 오류는 문법 오류로 인식되기 전에 **어색한 소리**로 먼저 감지된다. 확신이 없으면 어미가 붙지 않는 문장 구조로 우회하거나 `needs_native_check`로 표시한다.

## 6. 키릴 표기와 렌더링

몽골어 키릴 35자 = 러시아어 33자 + **`Өө`, `Үү`**.

이 두 글자가 렌더링 사고의 원인이다. 러시아어 지원만 확인한 폰트는 몽골어에서 두부(□)를 만든다. 폰트 선정 시 실제로 `Өө Үү` 렌더링을 확인한다. 안전한 선택: Noto Sans / Noto Serif 계열.

`Ёё`는 몽골어에서도 사용되며, 러시아어와 달리 생략하지 않는다.

### 인명 표기

몽골 이름은 `овог(부칭/성) + нэр(이름)` 순이며, овог는 소유격을 취한다:
- `Мэндсайхан` + `Энхболд` → **`Мэндсайханы Энхболд`**
- `Цогбадрах` + `Зул-Эрдэнэ` → **`Цогбадрахын Зул-Эрдэнэ`**

소유격 어미는 어간 말음과 모음조화에 따라 `-ын/-ийн/-ы/-ий/-гийн` 등으로 갈린다. 일상에서는 овог를 생략하고 이름만 부르거나, овог를 머리글자로 축약(`М.Энхболд`)한다. 친밀한 글에서는 이름만 쓰는 것이 자연스럽다.

### 비공식 로마자 표기

표준이 없어 사람마다 다르게 쓴다(`хайрдаа` → `khairdaa`/`hairdaa`, `хорвоод` → `horwood`). 당사자들이 실제로 쓰는 방식이 있으면 **그 방식을 그대로 따른다.** 표준화하려 들면 그들의 목소리가 지워진다.

## 7. 피해야 할 것

- **번역기 문체** — 한국어 어순을 그대로 따라간 몽골어. 특히 긴 관형절
- **과잉 존칭** — 배우자에게 `та`
- **억지 두운** — 운을 위해 의미가 뒤틀린 행
- **검증 안 된 이름 뜻풀이**
- **이미지 과적재** — 한 문단에 빛·꽃·별·하늘·바다를 다 넣기. 몽골 서정문은 이미지 하나를 끝까지 밀고 간다
- **러시아어 어휘 오용** — 형태가 비슷해도 몽골어에서 뜻이 다르거나 안 쓰이는 단어가 있다
